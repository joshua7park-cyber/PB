# Parallel Bible (by Joshua Park) — iPhone web app

Open this site once in Safari, tap Share → **Add to Home Screen**, and it works offline from then on.
Only freely shareable translations are stored here (개역한글 1961, BSB, WEB, KJV, 口語訳, 文語訳, AYT).
Personal-use translations are moved onto the phone with a backup file and never leave the phone.
Fonts: Nanum Myeongjo (SIL OFL 1.1).
